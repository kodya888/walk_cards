# Гуляю-собираю

PWA-приложение: выходишь гулять — получаешь карточку с чудиком.
Три режима поиска открываются по мере освоения.

## Как запустить на компьютере

Геолокация в браузере работает только по `http://localhost` или `https://`.
Открывать `index.html` двойным щелчком (`file://`) нельзя — карта и геолокация не заработают.

```bash
cd C:\Users\ADMIN\Documents\ai_moi\walk_cards
C:\Python314\python.exe -m http.server 8123
```

Затем открыть в браузере: **http://127.0.0.1:8123/**

Отладочные кнопки (симулятор прогулки) появляются с адресом:

```
http://127.0.0.1:8123/index.html?debug=1
```

- **пройти 350 м** — сдвигает тебя, будто ты ушёл гулять
- **к цели** — телепортирует к текущей цели (нажать дважды: нужно два замера подряд)

## Как проверить на телефоне

С телефона `http://192.168.x.x` не даст геолокацию — нужен HTTPS.
Поэтому: выкладываем папку на GitHub Pages и открываем ссылку с телефона.

## Режимы

| Режим | Условие | Награда | Открывается |
|---|---|---|---|
| Выйти за круг | уйти больше 300 м от точки старта | обычная карточка | сразу |
| Найти точку | дойти до точки, которую сам поставил (300–700 м) | обычная, шанс редкой тем выше, чем дальше | сразу |
| Маршрут | 2 точки подряд | редкая гарантированно | после 3 прогулок |

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | разметка экранов: карта, панель старта, карточка, коллекция |
| `style.css` | оформление (карточка взята из проекта «Пословицы») |
| `app.js` | вся логика: карта, геолокация, проверка расстояний, сохранение |
| `cards.js` | данные карточек и выбор награды |
| `sw.js` | офлайн-кэш (service worker) |
| `manifest.json` | описание PWA для установки на телефон |
| `vendor/leaflet/` | библиотека карт Leaflet (локальная копия) |
| `img/` | картинки чудиков (SVG) |
| `icons/` | иконки приложения (пока временные, от «Пословиц») |

## Как добавить карточку

1. Положи картинку в `img/` — лучше SVG, он в 15 раз легче PNG.
2. Открой `cards.js` и добавь запись:

```js
{
  id: 'moy-chudik',
  name: 'Мой чудик',
  img: 'img/moy-chudik.svg',
  rarity: 'common',
  desc: 'Что-то смешное про него.'
}
```

3. Добавь файл в список `ASSETS` в `sw.js` и **подними `VERSION`** (например `wc-v2` → `wc-v3`).
   Без этого телефон продолжит показывать старую копию.

## Как менять правила

Всё в начале `app.js`, объект `CFG`:

| Параметр | Значение | Что значит |
|---|---|---|
| `CIRCLE_R` | 300 | радиус круга, м |
| `POINT_MIN` / `POINT_MAX` | 300 / 700 | куда можно ставить точку |
| `HIT_R` | 80 | радиус, с которого точка считается найденной |
| `ROUTE_LEN` | 2 | точек в маршруте |
| `ROUTE_UNLOCK_WALKS` | 3 | после скольких прогулок открыть маршрут |

## Карта

Leaflet + тайлы OpenStreetMap. Ключи API не нужны, платить не надо.

Кнопка «Как дойти» открывает Яндекс.Карты с уже построенным пешеходным маршрутом —
это обычная ссылка, никакого API и никаких ключей.

## Известные ограничения

- Геолокация в браузере требует HTTPS (GitHub Pages подходит).
- Официальные тайлы OSM нельзя кэшировать и нельзя гонять на них большой трафик —
  для личного проекта нормально, для публичного надо брать тайл-провайдера.
- iOS Safari: карта и геолокация работают, псевдо-AR (если будем делать) — только в Safari.
- Симулятор нужен потому, что на ноутбуке координаты определяются по Wi-Fi с точностью 1–5 км.
