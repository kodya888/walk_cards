# Хэндоф-памятка: пак «Цветы» + подарки по ссылке + живой тюльпан

Обновлена: 2026-11-19, вечер. Пишу для новой сессии (партнёр зайдёт отдельно).

## Суть
Пак «Цветы» (10 карточек) как подарок жене без покупок: партнёр собирает карточки
на прогулках (функция уже есть), жмёт «Подарить» → приложение даёт ссылку
`?gift=КОД&from=Имя`. Ссылку кидает в мессенджер; жена открывает — попадает в
режим «Тебе подарок»: рубашка → тап (переворот + анимация) → тап (на весь экран)
→ «Забрать» (+1 в коллекцию). Ориентир по красоте — телеграм-подарки. Прототип
без покупок: «посмотрим на реакцию супруги».

## Живой тюльпан (карточка 02) — ход эксперимента
Идея партнёра, одобренная направлением: «я задам картинку — ты её заанимируешь»
(свой способ делать карточки, НЕ LottieFiles). Образец — `otladka/i.webp`
(тюльпан на белом фоне, 447×740).

- Генератор: `tools/make_tulip_from_image.py` (Pillow + рукописный Lottie JSON).
  Пайплайн: key_out_white (floodfill из 6 точек маджентой thresh=12 → альфа 0,
  потом MinFilter(3) по альфе + blur 0.6 — срезает белую кайму) → резка на
  «голову» (бутон, crop до head_bottom+12px в стебель) и основу (стебель+
  листья) → слои: 2 падающих лепестка (вектор, цикл на 180 кадров), основа
  «дышит» (100→101.5%), голова качается ±2.6° вокруг шарнира (стык 40% высоты
  от низа бутона), 3 блёстки-звездочки (вспышка по окну t_in..t_out).
  Картинки вшиты base64 PNG (`"e":1`,`"u":""`). Выход ОБА файла:
  `otladka/tulip_anim.json` (превью) и `img/flowers/02_tulip.json` (карточка)
  — скрипт пишет оба сам.
- Превью-страница: `otladka/tulip_preview.html` (два бокса: карточка/большая).
  Смотреть только через http.server (fetch с file:// блокируется CORS):
  `cd walk_cards && python http.server 8127 --bind 127.0.0.1` →
  `http://127.0.0.1:8127/otladka/tulip_preview.html`.
- **Фидбек партнёра 2026-11-19: «движения почти не видно».** Параметры сейчас:
  качание ±2.6° за 6с, «дыхание» 1.5% за 3с, лепестки полупрозрачные 65%,
  блёстки мелкие (10–16px). НА СЛЕДУЮЩИЙ ШАГ: усилить заметно — качание
  до ±7..9° (и/или добавить лёгкий сдвиг головы), дыхание 3–4%, лепестки

  переснять скрины (`_tulip_v2_a.png` — актуальный вид), показать партнёру.
